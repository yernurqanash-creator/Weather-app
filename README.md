# Weather Console Application (Java)

This is a simple **console-based weather application** written in Java.  
The project fetches weather forecast data from the **OpenWeather API** and displays it in the terminal.

The application is built using **Maven** and demonstrates:
- HTTP requests in Java
- Working with external APIs
- JSON parsing
- Basic project structure with Maven

---

## Features
- User enters a city name in the terminal
- Application sends a request to OpenWeather API
- Weather forecast data is received in JSON format
- Forecast is parsed and printed in a readable form
- Error handling for invalid city names and network issues

---

## Technologies Used
- Java 17
- Maven
- OpenWeather API
- org.json library
- VS Code
